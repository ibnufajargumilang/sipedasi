Sistem SiRekon

Panduan lengkap pengelolaan Rekonsiliasi Pajak Daerah (PBB, BPHTB, PJDL). Pelajari cara import data, menggunakan filter canggih, hingga manajemen pelaporan.

Fitur Unggulan

Import Excel Instan

Sistem membaca file Excel secara cerdas. Tidak perlu pusing dengan format kolom, sistem akan mencari header seperti Pokok, Denda, dan Total secara otomatis.

Smart Filtering

Analisa data lebih dalam dengan filter multi-layer: Rentang Tanggal, Jenis Bank / Channel Pembayaran, hingga Jam Transaksi.

Data Safety & Reset

Salah filter atau tidak sengaja menghapus data? Tenang. Fitur Reset akan mengembalikan kondisi data persis seperti saat pertama kali diupload.

Fully Responsive

Akses dashboard dari Laptop, Tablet, maupun Smartphone dengan tampilan yang menyesuaikan secara otomatis.

Catatan Teknis

Format Tanggal: Pastikan kolom tanggal di Excel berformat Date, bukan Text. Sistem menggunakan mode CellDates: True untuk akurasi tinggi.

Format Angka: Angka dibaca sebagai Raw Number. Jangan gunakan pemisah ribuan berupa teks manual. Biarkan Excel memformatnya, sistem akan membaca value aslinya.

FAQ & Troubleshooting

Filter "Jenis Bank" cuma muncul 1 data?
Kemungkinan nama bank di Excel tidak konsisten (spasi ganda).
Solusi: Upload ulang file Anda. Sistem v2.0 memiliki fitur Auto-Fix yang akan membersihkan spasi tersebut secara otomatis.
Tanggal terbaca angka 45xxx?
Itu adalah "Serial Number" Excel. Pastikan kolom format cell di Excel adalah Date, bukan General/Text. Sistem akan berusaha membacanya, namun format Date asli lebih disarankan.
